# ASSET CREDITS — Cardboard Kingdom 3D

All installed game art is **CC0 (public domain)** by Kenney
(https://kenney.nl) — free for any use, no attribution required.
Credit is given here anyway, because it's the right thing to do.

| Pack | Used for | License |
|---|---|---|
| Kenney Tiny Town (130 tiles) | Trees, mushroom | CC0 |
| Kenney Roguelike Characters (450 sprites) | All 5 characters | CC0 |
| Kenney Roguelike RPG Pack (1700 tiles) | Crate, barrel | CC0 |
| Kenney Game Icons | Star (UI, staged) | CC0 |

**Not used:** Liberated Pixel Cup art was evaluated but not installed
— its share-alike license would complicate the project. Everything in
the game is CC0, keeping the game fully free with no strings.

**Derived work:** Reyes's cap + badge and Caw's tall hat were drawn
on top of Kenney character cells in `godot/tools/convert_sprites.py`
(also CC0, as a derivative of CC0 art).

**Regenerating:** re-download the packs into
`godot/assets/_packs/` (see `tools/convert_sprites.py` header) and run
`python3 godot/tools/convert_sprites.py`. The `_packs/` folder is
local staging and is not committed to the repo.
